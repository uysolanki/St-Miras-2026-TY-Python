Question 6) Define a class Date(Day, Month, Year) with functions to accept and display it. 
Accept date from user. Throw user defined exception InvalidDateException if the date is invalid.

Program 6)
class InvalidDateException(Exception):
    pass


class Date:

    def accept(self):
        self.day = int(input("Enter Day: "))
        self.month = int(input("Enter Month: "))
        self.year = int(input("Enter Year: "))

    def validate(self):

        if self.month < 1 or self.month > 12:
            raise InvalidDateException("Invalid Month")

        if self.day < 1 or self.day > 31:
            raise InvalidDateException("Invalid Day")

        if self.month in [4, 6, 9, 11] and self.day > 30:
            raise InvalidDateException("This month has only 30 days")

        if self.month == 2:
            leap = (self.year % 400 == 0) or (self.year % 4 == 0 and self.year % 100 != 0)

            if leap:
                if self.day > 29:
                    raise InvalidDateException("February has only 29 days")
            else:
                if self.day > 28:
                    raise InvalidDateException("February has only 28 days")

    def display(self):
        print("Date:", self.day, "/", self.month, "/", self.year)


d = Date()

try:
    d.accept()
    d.validate()
    d.display()

except InvalidDateException as e:
    print("Exception:", e)
	
Sample Output
Enter Day: 31
Enter Month: 2
Enter Year: 2024
Exception: February has only 29 days


Question 7) Write a text file named test.txt that contains integers, characters and float numbers. 
		Write a Python program to read the test.txt file and print appropriate message using exception.


test.txt
100
Hello
25.5
A
500

Program 7)
try:

    file = open("test.txt", "r")

    print("File Contents:")
    print(file.read())

    file.close()

except FileNotFoundError:
    print("Error: File does not exist.")

except PermissionError:
    print("Permission denied while opening the file.")

except Exception as e:
    print("Some other error occurred:", e)

else:
    print("File read successfully.")

finally:
    print("Program Ended.")
Output
File Contents:
100
Hello
25.5
A
500

File read successfully.
Program Ended.
